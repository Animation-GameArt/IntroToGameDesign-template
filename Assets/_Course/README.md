# _Course — course files

Everything in this folder belongs to the course. **Don't edit, move or rename anything in here.** Course updates overwrite this folder, so any change you make will be lost.

| Folder | Contents |
|---|---|
| `Core/` | The core scripts every exercise and game uses |
| `Exercises/` | Exercise scenes and prefabs |
| `Kits/` | Genre kits, added after your pitch is approved |
| `Games/` | Scripts written for one specific game |

- To change a course script, copy it into `Assets/_Game/` and edit your copy.
- When you open an exercise scene, use **File → Save As…** to save your own copy in `Assets/Scenes/Exercises/`, and work in that copy.
- `VERSION.txt` shows which version of the course files you have.
