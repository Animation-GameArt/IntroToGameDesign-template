# Physics Puzzle Kit

Scripts, UI and a sample game for physics puzzles: launching things at structures (Angry Birds style) and cutting ropes (Cut the Rope style).

| Folder | Contents |
|---|---|
| `Scripts/` | Launcher 2D, Breakable 2D, Puzzle Target 2D, Puzzle Rules, Rope 2D, Cuttable 2D, Cutter 2D |
| `UI/` | The kit's HUD |
| `Sample/` | A small sample game: scenes, prefabs and data |

The kit uses the course's Core scripts and Unity's built-in 2D physics. Like everything in `_Course`, don't edit these files; make prefab variants in `Assets/_Game`.

The kit guide is on the course site: **Physics Puzzle Kit**.
