# Genre Kits

Each genre kit adds scripts, screens and a small sample game for one kind of game: platformer, top-down adventure, turn-based battle, arcade classic, physics puzzle, and more.

Kits aren't part of the project download. From week 8, download the kit for your game from the course project's **Releases** page, and import it: with the project open, double-click the `.unitypackage` file and click **Import**. It arrives in this folder.

The Genre Map on the course site lists every kit and what it covers.
