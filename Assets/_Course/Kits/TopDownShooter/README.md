# Top-Down Shooter Kit

Scripts, a HUD and a sample game for shooters seen from above: twin-stick arena shooters such as Geometry Wars, and scrolling shooters such as 1942.

| Folder | Contents |
|---|---|
| `Scripts/` | Weapon (asset), Weapon Shooter 2D, Projectile 2D, Aim 2D, Enemy Mover 2D, Wave Spawner 2D, Power Up 2D, Drop On Death 2D, Keep On Screen 2D, Scroll Camera 2D, Wake On Screen 2D |
| `UI/` | The kit's HUD: health, score, wave and weapon |
| `Sample/` | The sample game: an arena with waves, and a short scrolling level |

The kit uses the course's Core and 2D scripts, and Kenney's Pixel Shmup art pack (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a prefab, a weapon or a screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Top-Down Shooter Kit**.
