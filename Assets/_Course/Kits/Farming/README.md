# Farming Kit

Scripts, a screen and a sample game for farming and life sims: till, plant, water, sleep, harvest, sell, and buy better seeds. The sample is one small field with three crops, a shop and a bed, and a money goal to reach in two weeks.

| Folder | Contents |
|---|---|
| `Scripts/` | Item and Crop (assets), Inventory, Farm Field, Farmer Tools 2D, Day Cycle, Interact Zone 2D, UI Farm Screen, UI Shop |
| `UI/` | The game screen: day, time, money and energy, the hotbar, prompts, the shop and the morning report |
| `Sample/` | The sample farm |

The kit uses the course's Core and 2D scripts, and Kenney's Tiny Town and Tiny Dungeon art packs (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change an item, a crop or the screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Farming Kit**.
