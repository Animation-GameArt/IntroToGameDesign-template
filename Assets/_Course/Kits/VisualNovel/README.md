# Visual Novel Kit

Scripts, a screen and a sample story for visual novels and dating sims, written with Yarn Spinner (installed in the course project from OpenUPM). The sample is a short story at a lantern festival with two characters to get to know and three endings.

| Folder | Contents |
|---|---|
| `Scripts/` | Character (asset), UI Dialogue Presenter (shows Yarn dialogue with UI Toolkit), Visual Novel Stage (backgrounds, characters and the script's commands), Yarn Variable Link, UI Relationship Meters |
| `UI/` | The visual novel screen: background, three character spots, relationship meters, choices and the dialogue box |
| `Sample/` | The sample story: `Story/LanternFestival.yarn`, its Yarn Project, characters and scenes |

The kit uses the course's Core scripts and Yarn Spinner. The sample's portraits are from Kenney's Tiny Dungeon (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. Write your own story in `Assets/_Game`, and copy the screen there if you want to change it.

The kit guide is on the course site: **Visual Novel Kit**.
