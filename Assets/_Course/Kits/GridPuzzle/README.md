# Grid Puzzle Kit

Scripts, screens and a sample game for puzzles played on a grid, one step at a time, in the style of Sokoban: push the boxes onto the targets. Every move can be undone.

| Folder | Contents |
|---|---|
| `Scripts/` | Grid Board, Grid Piece, Grid Goal, Grid Player Input, Level List (asset), Puzzle Level Loader, UI Level Select |
| `UI/` | HUD, level select and solved screens |
| `Sample/` | The sample game: a menu, a level select and eight levels |

The kit uses the course's Core scripts, and Kenney's Sokoban art pack (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a prefab, a level or a screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Grid Puzzle Kit**.
