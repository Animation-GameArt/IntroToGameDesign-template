# Endless Runner Kit

Scripts, a HUD and a sample game for endless runners: the player runs by themselves, faster and faster, and survives as long as they can. Three styles: jumping (Canabalt), jetpack (Jetpack Joyride) and lanes.

| Folder | Contents |
|---|---|
| `Scripts/` | Runner Controller 2D, Track Chunk, Track Spawner 2D, Parallax 2D, Coin Magnet 2D, Magnet Power-Up 2D |
| `UI/` | The kit's HUD: distance, best distance and coins |
| `Sample/` | The sample game: a jumping runner, with track chunks for each difficulty |

The kit uses the course's Core scripts, and Kenney's Pixel Platformer art pack (CC0) in `Assets/_Course/Art/Kenney`, the same as the Platformer Kit.

Like everything in `_Course`, don't edit these files. To change a prefab, a chunk or a screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Endless Runner Kit**.
