# Top-Down Adventure Kit

Scripts, UI and a sample game for top-down adventures in the style of the early Zelda games: explore rooms, fight with a sword, find keys, open doors.

| Folder | Contents |
|---|---|
| `Scripts/` | Melee Attack 2D, Knockback 2D, Top Down Chaser 2D, Key Door 2D, Camera Room 2D, Interactable 2D, UI Heart Row, UI Message Box |
| `UI/` | The kit's HUD, with a row of hearts and a message box |
| `Sample/` | A small sample game: scenes, prefabs and data |

The kit uses the course's Core and 2D scripts, and Kenney's Tiny Dungeon art pack (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a prefab or a screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Top-Down Adventure Kit**.
