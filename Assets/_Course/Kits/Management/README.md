# Management Kit

Scripts, a screen and a sample game for management and strategy games played in turns: look at your resources, make a few decisions, end the turn, see what happened. The sample is a small take on Hammurabi, with buildings you drag onto plots.

| Folder | Contents |
|---|---|
| `Scripts/` | Effect, Turn Rule (asset), Event (asset), Building (asset), Turn Cycle, UI Management Screen, UI Build Grid |
| `UI/` | The game screen: resources, building plots and cards, the turn report, End Turn, and the event panel |
| `Sample/` | The sample game: four resources, four buildings, rules, events, and ten years to survive |

The kit uses the course's Core scripts, and Kenney's Tiny Town art pack (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a rule, an event, a building or the screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Management Kit**.
