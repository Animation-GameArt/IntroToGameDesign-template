# Turn-Based Battle Kit

Scripts, UI and a sample game for turn-based battles in the style of classic role-playing games: pick an action from a menu, pick a target, and take turns until one side is out.

| Folder | Contents |
|---|---|
| `Scripts/` | Battle Action, Battle Actor, UI Battle Menu, Battle Log, Health Bar 2D |
| `UI/` | The battle screen: status, battle log and the action menu |
| `Sample/` | A small sample game: scenes, prefabs, actions and data |

The kit builds on the Turn Manager and Turn Taker from the course's Core scripts, which Exercise 05 (turn-based) introduced. It uses Kenney's Tiny Dungeon art pack (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a prefab, an action or a screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Turn-Based Battle Kit**.
