# Platformer Kit

Scripts, UI and a sample game for side-view run-and-jump games.

| Folder | Contents |
|---|---|
| `Scripts/` | The kit's scripts: Stompable Enemy 2D, Bounce Pad 2D, Platformer Sprite Animator |
| `UI/` | The kit's screens: HUD, menu and Level Complete |
| `Sample/` | A small sample game: scenes, prefabs and data |

The kit uses the course's Core and 2D scripts, and the Pixel Platformer art pack by Kenney (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a prefab or a screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Platformer Kit**.
