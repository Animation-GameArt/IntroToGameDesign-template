# Card Game Kit

Scripts, a screen and a sample game for card battle games in the style of Slay the Spire: draw a hand, spend energy to play cards, watch what the enemy will do next, end the turn. The sample, *Suit Duel*, uses a playing-card deck in which each suit does something different, against three enemies in a row.

| Folder | Contents |
|---|---|
| `Scripts/` | Card and Enemy (assets), Card Battle (deck, hand, discard, energy, turns, enemies), UI Card Battle |
| `UI/` | The battle screen: the enemy and its next move, the player's health, block and energy, the hand, piles and End Turn |
| `Sample/` | The sample game |

The kit uses the course's Core scripts, Kenney's Playing Cards Pack for the cards, and Kenney's Tiny Dungeon for the enemies (both CC0), in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a card, an enemy or the screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Card Game Kit**.
