# Tower Defense Kit

Scripts, a HUD with a build menu, and a sample map for tower defense games: enemies walk a path, and the player builds and upgrades towers beside it to stop them.

| Folder | Contents |
|---|---|
| `Scripts/` | Tower (asset), Tower 2D, Tower Projectile 2D, Build Spot 2D, Enemy Path 2D, Path Enemy 2D, Tower Wave Spawner, UI Build Menu |
| `UI/` | The HUD: money, lives, wave, the Start Wave button and the build menu |
| `Sample/` | The sample map: three towers with upgrades, four enemies and ten waves |

The kit uses the course's Core scripts, and Kenney's Tower Defense (top-down) art pack (CC0) in `Assets/_Course/Art/Kenney`.

Like everything in `_Course`, don't edit these files. To change a prefab, a tower or a screen for your own game, copy it into `Assets/_Game` and edit the copy.

The kit guide is on the course site: **Tower Defense Kit**.
