# 3D Platformer Kit

Scripts for 3D platformers, on top of the course's 3D scripts (Player Controller 3D, Moving Platform 3D, Bounce Pad 3D, Spin 3D) and Core scripts (Collectible, Checkpoint, Kill Zone, Respawner, Health). The sample is one small level of floating islands with twenty coins, three areas and a goal.

| Folder | Contents |
|---|---|
| `Scripts/` | Patrol Enemy 3D (stomp it, or it hurts), Crumbling Platform 3D, Blob Shadow 3D |
| `Sample/` | The sample level, built from Unity's basic shapes |

A 3D scene's camera uses the **Universal Renderer**. The camera is a Cinemachine Camera that orbits the player.

Like everything in `_Course`, don't edit these files. Copy what you want to change into `Assets/_Game`.

The kit guide is on the course site: **3D Platformer Kit**.
